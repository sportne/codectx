## Manual QA Scope

Manual QA is release evidence only. Do not commit temporary databases, rendered
bundles, or ad hoc QA scripts.

The manual pass should cover:

- editable CLI and built PEX `--version` and `--help`;
- indexing and `health --integrity` for Java, C++, Python, MATLAB, Go, and Rust fixtures;
- file-only and file/line `context --goal explain` in Markdown for every supported fixture;
- representative JSON and text context output;
- `symbols`, `context --symbol`, `neighborhood`, `inspect-node`, and `inspect-edge`;
- missing index, unsupported file, nonexistent symbol, and invalid line user errors.

## Manual QA Result

Pass.

Manual QA used the editable CLI and the built `dist/codectx.pex` artifact. The
pass verified:

- editable CLI and PEX `--version` reported `codectx 1.1.0`;
- editable CLI and PEX `--help` rendered the supported command list;
- Java, C++, Python, MATLAB, Go, and Rust fixtures indexed into temporary
  databases and passed `health --integrity`;
- file-only Markdown context rendered for every supported fixture and included
  anchor, ranked context item, confidence, and score-trace information;
- representative file/line context worked in JSON and text output;
- `symbols`, `context --symbol`, `neighborhood`, `inspect-node`, and
  `inspect-edge` worked against the Java fixture;
- missing index, unsupported file, nonexistent symbol, and invalid line cases
  returned user-facing failures without tracebacks.
